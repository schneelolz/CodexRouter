# 快速开始

## 启动与供应商

先按 [README](../README.md) 构建，在独立数据目录和空闲端口启动。若已有构建文件夹，保留 `codexrouter.exe` 相邻的完整 `ui/`。双击使用默认数据目录与端口；重复启动会尝试唤起同一数据目录的已运行实例。

管理页中，官方模式使用客户端自身的官方身份；中转模式使用供应商自己的 API Key。中转供应商先保存名称、完整 Base URL、密钥和可选模型，再在总览保存默认选择。基址不自动补 `/v1`；拉取模型不代表生成成功。设置模型覆盖会影响该供应商已有会话的后续请求。

已有会话保持原供应商。有绑定后供应商基址与认证方式锁定；名称、模型和密钥仍可修改。未知历史先在“会话管理 → 待登记会话”选择真实原来源，再由客户端重试，不要为完成登记而猜测供应商。

## 日常接入与恢复

“客户端与接入 → 日常使用”只预览、备份并修改原配置的 `openai_base_url`。确认后保存工作，由用户手动退出并从原入口重开 Codex。共享 CLI 后台可能继续使用旧连接；后台运行、配置接入和收到实际请求是不同状态。

登录、历史和项目仍使用原目录；接入不复制这些内容。已登录桌面生成、历史连续性与恢复仍待真实验收。独立测试入口不共享日常认证与历史，不能用来续接日常工作。

退出路由器不会自动恢复客户端直连。需要恢复时，在日常使用页面预览“恢复接入前配置”，确认后手动重开客户端。恢复的是原连接值，可能是原自定义地址。原目录中的 `.codexrouter-routing` 是恢复依据，不要删除它来处理冲突。

## 请求与用量

用量明细只显示观察到协议成功完成的生成；HTTP 200 内的失败归错误，未能确认的响应归待确认。缺少的 token、首字时间等显示为未报告，不能视为零。输入已包含缓存子集，推理属于输出子集，不重复加总。TPS 使用输出 token 和总耗时，不能理解为账单或纯文本字速。

保留天数默认 0（不限期），可设 1～3650 天。清理仅删除符合条件的已结束请求，不删除 JSON 会话绑定、待登记或供应商。全部清除要求确认；数据库可能复用空间，不保证文件立即变小。

## 更新与保护

更新前正常停止对应路由器，整体备份数据目录；运行时的 SQLite 附属文件不能单独复制或删除。schema 3 回滚需要配套的升级前数据副本。凭据在 Windows Credential Manager，复制目录不迁移密钥。

管理入口令牌、Cookie、API Key、认证文件和运行数据均不应上传。遇到故障只提供稳定错误码、时间和必要脱敏关系。WebSocket、子代理、其他客户端版本及真实上游兼容性限制见[验收状态](acceptance-matrix.md)。
