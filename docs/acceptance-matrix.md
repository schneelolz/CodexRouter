# 验收状态

功能基线：0.5.0-test-usage1；本表区分自动化与真实使用，不能把历史版本的账号实测继承到当前源码。

| 范围 | 状态与边界 |
|---|---|
| 管理契约、后端、前端类型与用量格式 | 自动化检查结果见[验证记录](verification.md) |
| 固定供应商、默认切换、落盘失败、并发、重启恢复 | 有合成回归；真实账号不等同通过 |
| cold_fork / warm_fork | 有明确已绑定父线程才继承；warm 有独立 app-server 合成上游观察，不代表侧边 UI |
| thread/session 分离、子代理 | 仍严格校验，已知身份冲突未解决，不能宣称兼容 |
| ephemeral_fork | 未有可采用的推理请求证据，不启用 |
| HTTP/SSE、压缩、取消与超时 | 有合成回归；长期真实网络稳定性未验证 |
| 用量、200 内失败、待确认与 schema 迁移 | 有合成测试；上游未知格式可能降级统计 |
| SQLite 历史、游标、保留、清理 | 有自动化覆盖；未模拟物理断电/磁盘耗尽 |
| 页面四标签、分页、弹窗及键盘 | 浏览器验证使用合成数据，见验证记录 |
| 桌面独立启动 | 历史空认证隔离检查通过；登录后生成、原历史连续性及真实侧边 UI 未验证 |
| Windows 托盘 | 资源/生命周期有测试；真实菜单外观、多屏 DPI 与完整 Explorer 重启未完整验收 |
| 当前源码真实官方/API Key 上游 | 未验收；不继承早期单/双线路版本结论 |
| compact、真实断网及长期运行 | 未验证 |
| WebSocket 转发 | 未实现，返回 426，是否回退由客户端决定 |
| macOS/Linux 日常凭据与桌面 | 不属于已实现并实机验证的 Windows 交付范围 |

此次发布只上传核验后的源码与文档，不安装替换日常程序，也不上传本机测试数据、截图、旧历史或认证。原始证据仅本地留存，仓库提供可复核的测试入口和脱敏摘要。
