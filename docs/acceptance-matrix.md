# macOS 验收边界

macOS 开发候选提供原生 Keychain、菜单栏、`.app` 构建、Unix 私有存储和日常接入夹具。历史隔离验证见 [验证记录](verification.md)，最终整合与 CI 结果必须按具体提交记录。

| 范围 | 状态与边界 |
|---|---|
| Apple Silicon 原生服务、图标、信号与菜单动作 | 有本地合成验证；外部鼠标、外观及 Finder 操作未完整验收 |
| Keychain / 凭据空间 | 临时钥匙串隔离、拒绝、显式迁移/回滚有回归；不恢复系统钥匙串密码 |
| CLI / 临时 warm-fork | 外置五阶段、内置 app-server 八轮合成协议有证据；不代表真实账号或所有子代理 |
| 桌面隔离启动 | 未证明，继续由后端拒绝、界面禁用 |
| Intel / Windows | Mac 本地只有交叉构建证据，平台 CI 另行核对 |
| 发布与真实使用 | 无 Developer ID/公证、最低系统版本及真实账号长稳验收；HTTP 200 不等于语义完成 |

# 验收状态

| 范围 | 状态与边界 |
|---|---|
| 管理契约、后端、前端类型与用量格式 | 自动化检查结果见[验证记录](verification.md) |

| ephemeral_fork | 未有可采用的推理请求证据，不启用 |
| HTTP/SSE、压缩、取消与超时 | 有合成回归；长期真实网络稳定性未验证 |
| 用量、200 内失败、待确认与 schema 迁移 | 有合成测试；上游未知格式可能降级统计 |
| SQLite 历史、游标、保留、清理 | 有自动化覆盖；未模拟物理断电/磁盘耗尽 |
