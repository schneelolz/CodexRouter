# 发布隐私与维护

## 本次发布

本仓库使用经过筛选的源码快照建立新的首次提交。原本地开发仓库、提交历史和未提交工作保留在原位置，不作为此仓库父历史上传。仓库采用 AGPL-3.0-only 公开发布。首次公开时，已将经审查的当前源码整理为一个无父提交的 `Initial commit`；原公开前历史仅作本地备份，不创建远端备份分支或标签。

纳入内容为 Go 源码及测试、前端源码和锁文件、管理契约、现用构建/检查/协议探针脚本、通用文档与第三方依赖许可证。移除了源码中一个维护者私人目录特判；UNC 和其余日常配置保护保留。第三方署名和许可证原样保留，明确合成的测试地址与夹具不是实际凭据。

不纳入本机交接与问题原文、原始会话协议 JSON、旧 Git 对象、临时截图、旧打包脚本、构建产物、node_modules、运行状态、SQLite、认证、环境文件、登录链接及系统凭据。原始材料留在原开发仓库本地，不纳入公开仓库。

## 后续提交

更新来自原开发工作区时应再次审查差异，不直接推送原历史，也不无筛选覆盖此副本。文档中的功能、版本、测试命令和通过结论要以实际代码及本次执行记录为准；旧版本与合成结果不得替代真实账号/桌面验收。

提交前检查暂存清单、个人路径、内网服务、令牌/私钥、原始会话标识以及截图/trace。`.gitignore` 只是防误纳入，不会清除已跟踪文件或历史。发现秘密后应先处理泄露与凭据，再决定历史清理；不能只在新提交中遮盖旧值。

本次模式扫描与人工审查降低已发现的隐私风险，不构成永久无泄露保证。测试和实际运行会新建含私人元数据的文件，均须留在仓库外或忽略目录。
